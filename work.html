Smart City System · .NET 8 + React 19 + Flutter

1. Smart Traffic & Emergency Management System (STMS)

Real-Time GPS Vehicle Tracking, SignalR Hub Dispatch, & Multi-Role Smart City Portal

GitHub Repository ↗ Full Deep Report →

🏗️ Solution Architecture

  • Backend: .NET 8 (C#) Clean Architecture (`src/`).
  • Database: SQL Server + EF Core with Custom Non-Clustered Indexes for high-concurrency queries.
  • Real-Time: SignalR Hubs for location streaming & live chat.
  • Web Portal: React 19 + Vite (Premium Dark Theme).
  • Mobile App: Flutter (Dart) + Riverpod + Google Maps API.

👥 5 User Roles

  • Driver (Flutter): SOS (Towing, Fuel, Battery, Flat Tire), live GPS tracking, incident reporting.
  • System Admin (React): Service provider onboarding approval, system revenue analytics.
  • CS Agent (React): SignalR live support chat & driver lookup/ban.
  • Rescue Provider (React): SOS task acceptance & earnings graph.
  • Store Seller (React): Spare parts catalog & order processing.

🔒 Security & Optimization

  • Auto Token Refresh: Background HTTP Interceptor renewing expired JWTs without user logout.
  • Stripe HMAC Security: Webhook signature verification preventing fraudulent payment events.
  • Custom Indexes: DB index tuning on high-frequency tables (Orders, Traffic Reports, Vehicles).

4. El Mogy Fresh — Organic E-Commerce Platform

4-Layer Clean Architecture, DDD, Hybrid Session-to-User Shopping Cart Merging

Live Site Demo ↗ GitHub Repository ↗ Full Deep Report →

🛒 Hybrid Shopping Cart

  • Guests shop seamlessly via Session/Cookies.
  • Upon login, guest items automatically merge into user account without losing cart data.
  • Hosted GuestCartCleanupBackgroundService automatically clears expired guest session carts.

🏗️ 4-Layer DDD Architecture

  • FreshVeg.Domain: Entities (Product, Order, Cart, Review).
  • FreshVeg.Application: Services & DTOs.
  • FreshVeg.Infrastructure: DbContext, Repositories & Unit of Work.
  • FreshVeg.Web: Controllers, Admin Area, & Background Workers.

🎨 UI & Multilingual

  • Modern Glassmorphic dark design system.
  • Multi-language support via custom LanguageController.
  • ASP.NET Core Identity with Role-Based Authorization (`Admin` / `User`).

5. Driver License Management System

Strict 3-Tier Architecture, 3NF SQL Server Relational Database, & Operation Audit Logging

GitHub Repository ↗

Key Capabilities & Architecture

  • Full License Lifecycle: Complete workflow for driving test tracking, first-time license issuance, renewal, replacement for lost/damaged licenses, and detaining/releasing licenses.
  • 3-Tier Architecture: Strict layer isolation between Presentation (WinForms), Business Logic (C# Domain Classes), and Data Access (ADO.NET Data Access Layer).
  • 3NF Database Design: Relational SQL Server schema designed in 3rd Normal Form with foreign key constraints and transactional consistency.
  • User Activity Logging: Integrated operation logging tracking every user action, test record modification, and status change.
