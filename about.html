My Journey & Mindset

Building Scalable Systems That Solve Real Problems

I'm Mohamed Ashraf, a Full Stack .NET Developer specializing in ASP.NET Core, C#, Entity Framework Core, SQL Server, and React. My approach centers on writing clean, maintainable code that directly serves business objectives.

During my intensive training at the Information Technology Institute (ITI) and through building production applications like El Mogy Fresh, STMS, CurexMind, and TechStore, I developed a strong foundation in 4-Layer Clean Architecture, Domain-Driven Design (DDD), and relational database performance optimization.

Beyond engineering, I am passionate about knowledge sharing. I volunteered as an instructor for the "Introduction to Backend Development with C# and SQL" program under the MTIS-HUB initiative, mentoring student developers in backend fundamentals, OOP concepts, database design, and SQL queries through practical coding sessions.

Engineering Core Principles

1. Data Integrity & Security

Protecting user records using JWT bearer authentication, OTP email verification, and strict DTO mapping.

2. Database Efficiency

Designing normalized 3NF schemas with custom non-clustered SQL indexes to avoid bottleneck queries.

3. Separation of Concerns

Isolating domain rules from HTTP controllers and database contexts to ensure long-term testability.

4. Clear Communication

Providing transparent progress updates, structured documentation, and honest technical recommendations.
