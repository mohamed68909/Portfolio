Smart City Platform

STMS — Smart Traffic & Emergency Response

Integrated smart city emergency dispatch platform with real-time SignalR location telemetry and React 19 dashboard.

1. Problem Statement & Architecture

City emergency dispatch systems require instant real-time telemetry to track rescue vehicles (towing, jumpstarts, fuel delivery) without HTTP polling overhead. The system supports 4 distinct user roles: System Admin, CS Agent, Rescue Provider, and Store Seller.

2. Real-Time Telemetry & Security

  • SignalR Hubs: Real-time Google Maps GPS location streaming and live support chat.
  • Stripe HMAC Webhooks: Secure payment processing verifying webhook signature headers.
  • JWT Refresh Interceptors: Automatic token refresh in React 19 Axios interceptors to keep users logged in.
